# Paste-ready prompts

Five files, in plain view rather than inside the hidden `.claude` directory. Open the one that matches your situation. The first four explain what to paste or attach; the fifth is the visible bundle used by limited browser mode.

- [claude-code.md](claude-code.md) is the nudge to use if Claude Code answers like a general chatbot instead of a household planner. Most of the time you will not need it, because Claude Code reads this folder by itself.
- [codex-cli.md](codex-cli.md) is the one prompt to paste at the start of a Codex CLI session inside this folder.
- [limited-browser-mode.md](limited-browser-mode.md) is for ChatGPT, Claude in a browser, or any other chat window on a website. Read its privacy warning before you attach household files.
- [family-ops-browser-bundle.md](family-ops-browser-bundle.md) is the one visible instruction file used by limited browser mode. It contains the standing rules and all seven jobs, so you do not attach hidden skill files.
- [install-the-assistant.md](install-the-assistant.md) is for people who do not have Claude Code or the Codex CLI yet. Paste it into whatever assistant you already have open and it will walk you through the install.

None of these replaces downloading the folder. They are how you switch the downloaded folder on inside the assistant you use.

If you are running Claude Code or the Codex CLI in this folder, the shortest path is to type `Start the kit` and skip all four files.
